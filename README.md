# 🌿 FocusFlow AI

### Your AI-powered student productivity companion

FocusFlow AI is a student-focused productivity project designed to help organize academic responsibilities, prioritize tasks, and manage time more effectively with AI assistance.

## ✨ Features

- 📋 **Task Management** — Organize academic tasks and responsibilities.
- 🧠 **AI-Powered Prioritization** — Intended to help students identify important tasks.
- 🎯 **Student Productivity** — Designed around the needs of students balancing coursework, projects, and deadlines.
- 🌱 **Minimalist Interface** — A calm, modern dashboard inspired by warm neutrals and forest-green accents.
- ☁️ **AI Agent Integration** — Planned integration with Strands Agents and Amazon Bedrock.

> Note: Features and integrations are subject to the current implementation. Planned features should not be considered complete until tested.

## 🛠️ Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **AI Agents:** Strands Agents
- **AI Infrastructure:** Amazon Bedrock
- **Version Control:** Git and GitHub

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd FocusFlowAI
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Start the backend

```bash
python focusflow_python_backend.py
```
